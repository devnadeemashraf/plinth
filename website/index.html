Clean Architecture

Strict Dependency Inversion

In traditional frameworks, business logic is tightly coupled to ORM entities, HTTP request objects, and cloud vendor SDKs. Migrating a database or web server requires a complete rewrite.

Plinth isolates domain logic inside an immutable core. All external capabilities are modeled as TypeScript interfaces (Ports). Implementations (Adapters) satisfy shared black-box contract tests.

  • ✓ Automated architecture fitness tests fail CI if core imports infrastructure
  • ✓ Identical contract test suites run against SQLite, PostgreSQL, and MySQL
  • ✓ Switch between high-performance Fastify or Express with one line
// 1. PRIMARY DRIVING ADAPTERS (INBOUND)

↓ [Requests & TenantContext]
// 2. APPLICATION & DOMAIN MODULES

Developer Experience

Designed for Modern TypeScript

Strict compile-time safety, zero runtime code generation, and clean ergonomics across your entire application. 

// Type-safe Route Contract: Generates handlers, client types, and OpenAPI 3.1
import { defineRoute, z } from "@plinth/core";

export const createPostRoute = defineRoute({
  method: "POST",
  path: "/api/v1/posts",
  summary: "Publish a new social feed post",
  tags: ["Social Feed"],
  bodySchema: z.object({
    content: z.string().min(1).max(500),
    tags: z.array(z.string().max(30)).max(5).default([]),
  }),
  responseSchema: {
    201: z.object({
      id: z.string().uuid(),
      authorId: z.string().uuid(),
      content: z.string(),
      createdAt: z.string(),
    }),
  },
});
// O(1) BigInt bitmask authorization engine: sub-nanosecond checks
export const PERMISSIONS = {
  POST_CREATE:     1n << 0n,
  POST_DELETE:     1n << 1n,
  COMMENT_CREATE:  1n << 2n,
  MODERATE_FEED:   1n << 3n,
  ADMINISTRATOR:   1n << 63n,
} as const;

export function hasPermission(userMask: bigint, required: bigint): boolean {
  if ((userMask & PERMISSIONS.ADMINISTRATOR) === PERMISSIONS.ADMINISTRATOR) {
    return true; // Superadmin bypass
  }
  return (userMask & required) === required;
}
// Dual-layer PII Redaction: Sanitizes structured logs and message bodies
import { createLogger } from "@plinth/core";

const logger = createLogger({
  serviceName: "social-api",
  environment: "production",
  redactKeys: ["password", "token", "secret", "authorization", "creditCard"],
});

// Output: {"email":"[REDACTED_EMAIL]","token":"[REDACTED_SECRET]"}
logger.info({ email: "user@example.com", token: "secret_token_abc123" }, "User logged in");
// Composition Root: Wire swappable adapters into clean ports
import { FastifyHttpAdapter } from "@plinth/adapter-fastify";
import { PostgresDatabaseAdapter } from "@plinth/adapter-postgres";
import { RedisCacheAdapter } from "@plinth/adapter-redis";

const db = new PostgresDatabaseAdapter({ connectionString: env.DATABASE_URL });
const cache = new RedisCacheAdapter({ url: env.REDIS_URL });
const http = new FastifyHttpAdapter({ port: env.PORT });

// Start the platform with zero framework leakage
await db.connect();
await http.listen();
