Production Architecture

Built on Non-Negotiable Invariants

Clean boundaries prevent your codebase from degrading into spaghetti as your application grows from prototype to scale.

Hexagonal Architecture

Strict Ports & Adapters

Your business services and domain entities never import Fastify, Express, PostgreSQL, or Redis. They communicate exclusively through strongly-typed TypeScript Port interfaces.

Performance

O(1) Bitmask Authorization

Evaluate permissions in less than 0.5 nanoseconds using 64-bit integer bit arithmetic. Check granular user, role, or moderator rights without touching your database.

Multi-Tenancy

Compile-Time Context Isolation

TenantContext is safely tracked across async call stacks via Node.js AsyncLocalStorage. Accidental cross-tenant data leaks are physically blocked at the repository level.

Security & Privacy

Dual-Layer PII Redaction

Sensitive fields like passwords, tokens, API keys, and emails are scrubbed before logging via pre-flight key inspection and deep regex stream sanitization.

API Contracts

Contract-First Zod & OpenAPI

Declare request parameters, headers, query strings, and response shapes once in Zod. Plinth generates typed handlers, 422 Problem Details validation, and OpenAPI 3.1 documentation.

CI / Quality Gates

Automated Fitness Scanners

Automated architectural fitness tests enforce architectural boundaries in CI. If a developer accidentally imports an infrastructure driver into core domain code, CI fails immediately.

Developer Experience

Clean, Idiomatic TypeScript

No decorators, no reflection metadata, no magic runtime containers. Just readable, statically verifiable code.

TypeScript 7.0 ESM 
// 1. Declare Route Contract: Auto-generates validation & OpenAPI 3.1 specs
import { defineRoute, type RouteContract } from "@plinth/core";
import { z } from "zod";

export const createNoteRoute: RouteContract = defineRoute({
  method: "POST",
  path: "/api/v1/notes",
  summary: "Create a new note",
  tags: ["Notes"],
  bodySchema: z.object({
    title: z.string().min(1).max(200),
    content: z.string().max(20000).default(""),
    isPinned: z.boolean().default(false),
    tags: z.array(z.string()).default([]),
  }),
  responseSchemas: {
    201: noteSchema,
  },
});
// 2. O(1) Bitmask Authorization: Zero database lookups to verify access
export const PERMISSIONS = {
  NOTE_READ:     1n << 0n, // 1n
  NOTE_WRITE:    1n << 1n, // 2n
  NOTE_DELETE:   1n << 2n, // 4n
  NOTE_MODERATE: 1n << 3n, // 8n
  ADMINISTRATOR: 1n << 63n, // Superadmin bit
} as const;

export function hasPermission(userMask: bigint, required: bigint): boolean {
  if ((userMask & PERMISSIONS.ADMINISTRATOR) === PERMISSIONS.ADMINISTRATOR) {
    return true; // Instant bypass
  }
  return (userMask & required) === required;
}
// 3. Composition Root: Wire secondary adapters into clean domain ports
import { FastifyHttpAdapter } from "@plinth/adapter-http-fastify";
import { StubNotesRepository } from "./infrastructure/stub-notes-repository.js";
import { NotesService } from "./services/notes-service.js";

const repo = new StubNotesRepository();
const service = new NotesService(repo);
const http = new FastifyHttpAdapter({ port: 3000, host: "127.0.0.1" });

http.registerRoute(createNoteRoute, async (req) => {
  const note = await service.createNote(req.body);
  return { statusCode: 201, body: note };
});

await http.listen();
